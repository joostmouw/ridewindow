<objective>
Build a custom "Add to Home Screen" instructional overlay that appears on every session in iOS Safari browser mode and permanently disappears once installed, satisfying PWA-03. This is a deliberately different, simpler component than the existing `ScreenHintOverlay` one-time coach-mark pattern (per D-04) — no `shared_preferences` persistence, detection is purely reactive to the browser's `display-mode: standalone` media query.

Purpose: iOS has no native install-prompt UI (unlike Android Chrome's `beforeinstallprompt`), so users must be told explicitly to use Safari's Share → "Add to Home Screen" action, every time, until they actually install.
Output: A testable `isStandaloneDisplayMode`/`isIosBrowserMode` detection seam (native-Android-safe via conditional import) + the `AddToHomeScreenOverlay` widget wired into the app shell.
</objective>
