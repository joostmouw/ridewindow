# Schets 016: Groepsritten

Milestone v4.2 Clubs, fase 35. Artifact: https://claude.ai/artifact/23usk1rbGJo89doiiNhZRa

## Vast
- Uitnodigen: groepen boven maatjes; een groep kiezen schakelt losse maatjes uit (groepsrit is
  alleen voor leden — de database laat buitenstaanders er bewust niet bij, 0012).
- Ritdetail: per lid gaat mee / kan niet / nog niet geantwoord, plus een telregel.
- Ritten-tab: groepschips (Alles + per groep) alleen als je in een groep zit (CLUB-26).
- Een groepsrit zonder antwoord krijgt dezelfde knoppen als een uitnodiging nu (CLUB-14).

## Gekozen (Joost, 2026-09-24)
- **Vraag 1: A.** Rood bolletje op "Ritten" in de onderbalk én het getal bij de tab Peloton (CLUB-25).
- **Vraag 2: B.** Groepsnaam vooraan in de rolregel onder de tijd, geen extra regel. Joost: *"Het
  moet passen op het scherm, dat is het belangrijkste."* Dus: lange groepsnamen afkappen met
  ellips, kaart nooit hoger dan nu, ook niet op 360 dp. Op het ritdetail staat de naam wél als chip bovenaan.
