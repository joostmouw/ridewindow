## Wat deze milestone heeft geleerd

Vier bugs van dezelfde familie, alle vier gevonden doordat iets op een echt toestel of tegen de
echte database werd gedraaid, en geen van vier vindbaar in een unit-test:

1. **Policy zonder grant, en grant zonder policy.** `group_rides` had een insertpolicy die klopte
   maar een SELECT-policy die de eigen nieuwe rij niet toeliet bij `INSERT ... RETURNING`;
   `feedback` had een policy voor anonieme inzendingen maar geen grant voor `anon`. Postgres
   controleert rechten vóór policies — beide lagen moeten kloppen, en de ene repareren zonder de
   andere levert niets op.
2. **Een `stable` functie ziet de rij niet die in dezelfde statement ontstaat.** Dat brak elke
   `.insert().select()` op een tabel waarvan de SELECT-policy zo'n helper gebruikt.
3. **Een stille mislukking ziet eruit als succes.** `_runAccountSync` slikte fouten in, de outbox
   laat een rij na een pogingenplafond vallen, en het accountscherm zei in beide gevallen "Synced".
   Daardoor stond een echt account maandenlang zonder profielrij in de database.
4. **Een foutmelding die naar de verkeerde oorzaak wijst is erger dan een vage.** Het uitnodigen
   toonde "die code is verlopen" terwijl er geen code in het spel was; dat kostte een halve sessie.

En één les die niet over code gaat: **de app mag geen huiswerk achterlaten.** Een tester opende een
deel-link, kreeg "log eerst in en voer deze code in" te zien zonder inlogknop, en vroeg "En nu?" —
terwijl de app die code al kende. Zie het geheugenitem *Gemak voor de eindgebruiker*.
