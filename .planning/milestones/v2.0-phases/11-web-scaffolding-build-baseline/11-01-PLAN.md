Run `flutter create --platforms web .` from the project root. This scaffolds `web/index.html`, `web/manifest.json`, `web/favicon.png`, and `web/icons/Icon-192.png`, `Icon-512.png`, `Icon-maskable-192.png`, `Icon-maskable-512.png`, and appends a `platform: web` entry to `.metadata`'s `migration.platforms` list. Do not hand-edit any of the generated `web/` files in this task — accept Flutter's defaults verbatim per ARCHITECTURE.md ("do not hand-write these from scratch"); PWA-specific meta tags (apple-touch-icon etc.) are explicitly Phase 16 scope, not this phase.

In the same task, add the WEB-04 `kIsWeb` guards to `lib/main.dart`:
1. Add `import 'package:flutter/foundation.dart' show kIsWeb;` to the import block (alphabetically after the `package:flutter/material.dart` import, before `package:flutter_localizations`).
2. Wrap the two-statement sequence in `main()` — `await Workmanager().initialize(callbackDispatcher);` and the following `await Workmanager().registerPeriodicTask(...)` call — inside a single `if (!kIsWeb) { ... }` block. Keep both statements together inside one guard (they are not independently useful).
3. Inside `RideWindowApp.build()`'s `ref.listen<SlotsState>(slotsProvider, (_, next) { ... })` callback, wrap the existing body (`if (next is SlotsLoaded) { final slot = next.slots.firstOrNull; WidgetUpdateService.update(slot); }`) inside `if (!kIsWeb) { ... }` so the listener itself still registers identically on every platform, but performs no work on web.

This is a `kIsWeb` runtime guard on a call site, not a conditional import — per PITFALLS.md Pitfall 9, this is the correct pattern here because `workmanager` and `home_widget` are already safely importable Dart packages on every platform (they just have no web plugin implementation); do not introduce `dart:io`/`dart:html` conditional-import files for this, and do not push the guard down into `lib/platform/background_task.dart` or `lib/services/widget_update_service.dart` — the guard belongs at the call site in `main.dart` only, per ARCHITECTURE.md Pattern 1.
  </action>
